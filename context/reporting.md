# Context: Reporting

Automation reporting may consume:
- Katalon CSV
- JUnit XML
- Execution logs
- Device logs
- API logs

Typical metrics:
- Total
- Passed
- Failed
- Skipped
- Pass rate
- Fail rate
- Flaky rate
- Feature / sub-feature breakdown

Keep parsing, transformation, mapping, and presentation separated. Never fabricate metrics or execution evidence.
