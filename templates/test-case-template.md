# Test Case Template

Use the user's supplied spreadsheet template whenever available.

Typical fields:
- TC No
- Regression UAT
- Case
- Menu / Module
- Scenario
- Pre-condition
- Step
- Gherkin
- Expected
- Actual
- Assign Android
- Assign iOS
- Assign Web
- Status Android
- Status iOS
- Status Web
- Evidence Android
- Evidence iOS
- Evidence Web
- Link Jira
- Notes

Execution/result fields remain blank for newly generated cases.
